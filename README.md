# Grade-7 English Units 1–7 — Vercel Project

Static HTML/CSS/JS project. No build command or framework is required.

## Vercel
1. Upload this folder/ZIP to Vercel.
2. Framework Preset: Other (or leave auto-detected).
3. Build Command: leave blank.
4. Output Directory: leave blank.
5. Deploy.

The site is contained in `index.html`.
